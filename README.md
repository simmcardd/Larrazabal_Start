# Larrazabal Start

## Cordova Android Application

Successfully configured and tested using:

- macOS Apple Silicon
- Node.js and npm
- Cordova CLI 13.0.0
- Java JDK 17.0.20
- Android SDK
- Gradle 9.7.0
- cordova-android 15.1.0
- Android Emulator

## Build and Run

```bash
cordova platform add android
cordova build android
cordova run android
```

## Result

The application was successfully built, installed, and launched on an Android emulator.
